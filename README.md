# STA-CC: Static Timing Analyzer & Circuit Compiler

[![CI](https://github.com/antoniofsnascimento/STA-CC/actions/workflows/ci.yml/badge.svg)](https://github.com/antoniofsnascimento/STA-CC/actions/workflows/ci.yml)

An in-memory Static Timing Analysis (STA) engine and netlist compiler written in ISO C++20. Engineered with a Structure-of-Arrays (SoA) layout and cache-conscious DAG traversals for extreme gate-level evaluation throughput.

See `docs/SPEC.md` for functional contracts and `docs/ARCHITECTURE.md` for internal systems design.
